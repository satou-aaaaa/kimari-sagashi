# きまり探し

並んだ数・ひらがな・曜日・時計・形のきまりを見つけて、「？」に入るものを選ぶ1日5問のゲーム。大きな文字、押すだけ、時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/kimari-sagashi/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（何問続けて解けるか）、見つけたきまりが集まる「きまり帳」があります。
- まちがえても選び直せます。正解すると、きまりの説明が出ます。ヒントは「見るところ」→「選び肢を2つにしぼる」の2段です。
- 文字の大きさは3段から選べます（はじめは「大きい」）。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## このゲームについて（研究で分かっていること）

- 高齢の人2,832人が参加した ACTIVE 試験では、並びのきまりを見つける練習をした人は、その力が高く、10年後も差が残っていました（[Willis ほか 2006](https://doi.org/10.1001/jama.296.23.2805)・[Rebok ほか 2014](https://doi.org/10.1111/jgs.12607)）。
- ただし、練習した問題がうまくなることと、認知症にならないことは別です。WHO の指針（2019年）は頭の訓練を「勧めてもよい」としていますが、根拠の確かさは「とても低い〜低い」とされています（[WHO 2019](https://www.who.int/publications/i/item/9789241550543)）。
- このゲームは医療機器ではなく、認知症を予防したり治したりするものではありません。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
